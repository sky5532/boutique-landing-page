# Ma-U Boutique — Landing Page

A responsive boutique landing page built with **Bootstrap 5**, featuring a hero section, featured products, services, a newsletter signup, and a footer.

## 🔗 Live Demo
[View the live site](https://sky5532.github.io/boutique-landing-page/)

## Features
- Responsive navbar with logo and collapsible mobile menu
- Hero section with call-to-action button
- Featured products showcased in Bootstrap cards
- Services/features section highlighting shipping, quality, and returns
- Newsletter signup form
- Footer with social media links
- Custom favicon

## Built With
- HTML5
- Bootstrap 5 (via CDN)
- Git & GitHub
